# Windows Local Catalog Notes

Use `backend/catalog.json` to point each episode to a file under `media/`.

Example:

```json
{
  "media_path": "series/gilmore-girls/season-01/episode-01.mp4"
}
```

That means the real file must exist at:

```txt
media/series/gilmore-girls/season-01/episode-01.mp4
```
